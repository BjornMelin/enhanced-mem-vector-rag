# Support

Enhanced Memory supports Python 3.11 through 3.13, local SQLite files, the documented Python application programming interface (API), and the standard-input/output Model Context Protocol (MCP) tools on the latest 1.x release.

Open a GitHub issue for reproducible defects. Include the package version, Python version, operating system, a minimal example, and sanitized error output. Never attach a real memory database, credentials, security findings, or personal data to a public issue.

Remote hosting, authentication, managed storage, provider-specific embeddings, generic retrieval-augmented generation (RAG), crawling, document ingestion, graph databases, and migration from the unreleased prototype are outside the support contract.
